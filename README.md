# Weather App

## Introduction:

Made this weather for experience using API keys and related tasks

## Technical Details

### Key Features:

**City Search:**

- Text input for entering any city name

**Weather Display:**
- Current temperature (°C)
- Weather description (e.g. light rain, clear sky)
- Weather emoji representing current conditions

**Error Handling:**

- Friendly messages for invalid cities, bad API responses, and connection issues

### Platform:

Language: Python

GUI Framework: PyQt5

API: OpenWeatherMap
